# Regex patterns (Python syntax) for strings reproduced VERBATIM.
# One per line. Must match the WHOLE string to suppress translation.
# Also used by tr-lint to verify fragments survived unchanged.

# Slovene court case numbers:  I K 12345/2024,  II Kp 987/2023
[IVX]+\s+[A-ZČŠŽ][a-zčšž]{0,3}\s+\d+/\d{4}
# Generic file/reference numbers:  123-45/2024-6
\d+[-/]\d+([-/]\d+)*
# Dates in Slovene/German format:  5. 3. 2024   05.03.2024
\d{1,2}\.\s?\d{1,2}\.\s?\d{2,4}\.?
# Monetary amounts with currency
[\d.,]+\s?(EUR|USD|CHF|€|\$)
# Statute short forms, numbered:  KZ-1, ZGD-1, ZDavP-2, ZPIZ-2
# This form is structurally distinctive and needs no maintenance.
\b[A-ZČŠŽ][A-Za-zČčŠšŽž]{1,9}-\d+[A-Z]?\b
# Statute short forms, un-numbered. An explicit list, NOT [A-ZČŠŽ]{2,6}:
# that also matched any ordinary word set in capitals -- SKLEP, DA, NE, OK --
# so headings and short cell values were passing through untranslated.
# Add to this list as a matter requires.
\b(?:ZKP|ZPP|ZUP|ZIZ|ZUS|ZDR|ZGD|ZPIZ|ZDavP|ZFPPIPP|ZDIJZ|ZASP|URS|EKČP|OZ|SPZ|KZ)\b
# Currency codes standing alone
\b(?:EUR|USD|CHF|GBP|SIT)\b
# Bare identifiers / codes
[A-Z0-9]{2,}([-/][A-Z0-9]+)+
# Email and URLs
[\w.+-]+@[\w.-]+\.\w+
https?://\S+
